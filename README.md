# Bomi智绘服装工作台 3.4.4

这是本机运行的服装设计工作台。网页、智能组件和后台执行器共享项目、上传素材、任务和成片。软件品牌统一为 Bomi智绘，账号授权由本机安全服务完成。
全部设计操作可直接在工作台 UI 完成：提交任务后，后台使用已登录的 AI 服务自动读取报告、调用内置图像生成/编辑工具并保存结果。无需复制指令、切换对话，也不需要单独配置 OpenAI API Key。

## 打开与使用

可移动母版解压后，macOS 双击 `install.command`，Windows 双击 `install.cmd`。安装器会安装锁定依赖、运行测试、构建前端、安装插件并打开工作台。Node.js 20.9+ 是唯一需要预先安装的运行环境。

开发环境：

```sh
npm ci
npm run build
npm run open
```

免安装 Node.js 的桌面发行版可直接安装并启动 Bomi智绘。桌面版内置运行环境和 AI 组件，项目数据写入系统应用数据目录，不会写入只读安装目录。开发者可在对应系统上构建安装程序：

```sh
# macOS DMG
npm run desktop:dist

# Windows NSIS 安装程序（在 Windows 上执行）
npm run desktop:dist:win
```

未签名的本地 macOS 构建首次打开时，可能需要在 Finder 中右键选择“打开”。正式公开分发仍需配置 Apple Developer ID 或 Windows 代码签名证书。

工作台：<http://127.0.0.1:4174/>。`npm run open` 和插件首次调用都会自动启动共享的本机服务及任务执行器。关闭网页不影响后台任务，
但需要保持电脑开机、网络可用和本机服务运行。任务会使用当前账号额度；不会切换到另行计费的 API。
帐号与第三方 API 授权统一在设置中管理；授权由本机安全服务存储，Bomi智绘不读取或记录访问令牌。

Chat 模式提供工作台内的完整会话界面，支持多轮历史、参考图、PDF/趋势图附件、图片生成、趋势分析、实时任务进度和结果回显。可以直接输入：

> 使用 Bomi智绘工作台插件，查看并完成待处理任务。

也可以直接描述一个完整需求，例如：

> 在 Bomi智绘工作台中新建城市夜跑系列，使用我提供的趋势报告、模特和 Logo，生成 4 套造型，制作白底图并导出交付包。

### 网页工作流

1. 在全局“趋势资料库”批量上传 PDF、JPG、PNG 或 WebP；每张卡片显示解析状态，并可直接开始、暂停、继续或重试，无需切换到任务中心。解析完成后优先显示项目选择，重新解析、整理与归档收在卡片“更多操作”中。解析结果以瀑布流卡片展示，可按主分组、标签、状态整理和归档。永久删除只在归档视图的“更多操作”中提供，并会检查活动任务与项目引用；原文件和历史任务快照仍保留。
2. 在全局“素材库”批量保存模特、Logo 与图案；可在图片上直接拖动裁图框，拖拽四角自由缩放，也可锁定常用画幅。原图与历史裁剪始终保留并可一键恢复，每个项目都可复用。
3. 新建项目后默认进入“系列工作台”，选择 1 个主趋势、最多 2 个辅助趋势、1 个模特和 1 个 Logo 或图案。
4. 默认依据趋势报告生成同类风格系列，可改变服装搭配、配饰、妆发，并协调 Logo 的大小、颜色、工艺与风格；系列描述用于补充额外要求或限制。
5. 设置 1–12 套数量、Logo 尺寸或图案覆盖比例。检查清单会在当前页引导补齐缺项；后台先规划设计再逐张生成与检查。
6. 任务中心可独立选择模型、生成速度和并行任务数：首次运行优先选择账号中最新可用的 `Luna` 快速模型；稳定模式全局单张生成，快速模式全局同时生成 2 张，极速模式全局同时生成 3 张。默认最多同时执行 3 个趋势或项目任务，所有性能设置在重启后保留。每张任务卡根据状态只突出开始、暂停、继续或重试中的一个主操作；结束与“卡住时重启”保留在“更多操作”中。全局控制不会让一个失败任务阻塞其他任务。
7. 单张图片使用低推理、轻量化参考图和单次原生出图调用；仅生成 1 套时，设计规划与出图合并完成。500、连接中断或超时等瞬时服务异常会在当前图片内有限自动重试，无需重做已完成款式。每张图片生成后会实时出现在系列工作台和成片管理中，即使同系列其他图片仍在生成也可立即精修或制作白底图。
8. 成片管理按图片原始比例和真实像素尺寸展示结果。“款式调整”可一次上传多张参考图，并用提示词指定场景、配饰、发型、动作和道具等变化；参考图会随任务冻结并与原图一起发送给生成器。局部圈选或涂鸦改款会以独立透明图层保存；图层面板固定在改款中心的检查器中，同一位置可连续生成多个方案，逐层调整名称、显隐、顺序和不透明度，勾选满意方案后再合并为主图，所有合并或放弃操作保留历史。点击任何图片会进入统一的全屏看图界面，页面锁定不滚动，只保留切图、缩放、拖动和关闭，不再显示图层或任务操作。下载、改款、裂变等其他操作仍在成片卡片或对应工作区完成。“补齐白底”只处理尚缺图片；重新生成和归档放在“更多操作”中。成片需先归档，之后才能在归档视图的“更多操作”中永久删除；删除会自动写入项目历史。
9. 导出 ZIP 交付包，其中包含当前真实成片、所选资料引用、`manifest.json` 和 `design-notes.md`。

## 功能和边界

- 项目新建、重命名、分组、移动、删除；新项目不复制历史成片。
- 趋势和素材为跨项目共享资料库；支持一个主分组、多个标签、搜索筛选、卡片修订历史、可恢复归档。
- PDF、趋势图片、模特、Logo 与图案永久保存到本机，图像原件与标准化预览分别保存；应用不限制单文件大小、PDF 页数或批量文件数量，批量文件逐个安全入库。
- 四类真实任务：趋势解析、系列生成、白底处理、单图精修。
- 领取凭证防止重复执行；执行池最多同时处理 3 个趋势或项目任务，所有系列公平共享所选的 1–3 个全局图像槽位，避免多系列同时运行时放大服务端压力。不同项目可同时生成，趋势提炼不阻塞系列生成；同一张成片的精修与白底任务才会互斥。
- 失败、结束、重试与部分结果续做；服务重启后自动恢复，已保存成片不重复生成。持续 15 分钟无进度的运行任务会自动回收并继续，任务卡也提供手动“卡住时重启”。结束任务不撤销已经消耗的额度。
- 项目输入改变后禁止沿用旧快照重试，显示返回项目创建新任务的提示，旧结果保留下载。
- 少于要求数量不能完成；完成前检查图片，不能用占位图或旧成片冒充新结果。
- 同一项目每次新增系列都在现有成片后继续追加并使用连续 LOOK 编号，不清空、不替换旧图；新增系列运行时，既有成片仍可独立改款。全图改款保留叠图历史版本；局部改款使用非破坏图层待确认工作流，每次结果独立保留，最终合并后才成为新主图。参考图保存在安全文件仓库并参与重复结果校验；场景更新后旧白底不再冒充最新版本。
- 文件搜索、筛选、全选、素材无损裁剪与恢复、生成图原比例预览、历史下载、批量 ZIP 导出；支持桌面和手机尺寸。
- 浏览器实时轮询服务；参数草稿保存在当前浏览器会话中，点击保存或创建任务时写入服务。
- 原有森林/跑山系列由真实归档导入，跑山场景不会标为白底；旧 localStorage 项目以幂等方式迁移，旧缓存保留。
- v1 数据库首次打开时先保存 `state.v1.backup.json`，再按原始文件去重迁移为 v2 共享资料卡；项目、任务、成片与导出引用保持不变。
- 旧版没有保存过的上传原件无法恢复，旧版模拟“完成”也不会变成真实成果；此类项目明确提示重新上传。
- 本机单用户工具，不对公网开放。没有云端安装或公开商店发布。
- 模型不可用或额度不足时明确失败并保留结果。AI 人物一致性、Logo 文字、面料细节需要人工复核，设计效果图不等于可直接生产的打版文件。

### 自动执行实现

`server/executor.js` 管理并行任务池、冻结输入、分页渲染、设计计划、逐项验收、卡住回收和任务结束。
本机 AI 适配层负责检查账号与能力，并通过结构化只读任务执行隔离的设计步骤。
首次运行优先采用账号中最新可用的 Luna 快速模型；用户手动选择后会保留该设置。工作台复用当前账号登录，不读取或复制访问令牌；子进程清除 API Key 环境变量，并禁用插件、MCP 应用、浏览器、shell 和 hooks，使用只读沙箱。
参考图在临时任务目录准备并直接附加到单张生成请求；生成步骤固定使用低推理强度和一次原生图像调用。输出只接收本次受控任务生成目录下的真实图片，检查分辨率、重复像素、结果数后入库并立即交给用户复核；不会把外部路径返回值直接当作可信文件。
每个 AI 步骤超时上限 20 分钟，用户可提前结束。并行执行不意味着保证固定速度，耗时仍受网络、账号额度与生成复杂度影响。

## 插件结构与安装

插件源：`plugins/badmark-studio/`；共享 MCP 实现：`server/mcp.js`。
本机安装目录：`~/plugins/badmark-studio`；个人市场：`~/.agents/plugins/marketplace.json`。

```sh
npm run plugin:install
```

安装脚本会自动建立或更新个人插件市场条目，并将目标电脑的 Node 路径和当前项目目录写入已安装插件的 MCP 配置。移动目录后请重新运行安装。
源码 `.mcp.json` 使用相对路径，安装脚本会为目标机器生成带绝对路径的已安装配置。
升级已安装插件时使用 plugin-creator 的 cachebuster 流程后再安装，新的对话会加载更新后的工具。

## 可复用母版资产包

执行以下命令可生成不含业务数据和本机路径的跨电脑母版：

```sh
npm run master:package
npm run master:verify
```

发布目录、ZIP 和 SHA-256 校验文件位于 `releases/`。母版包含正式前后端、智能组件、初始化脚本、AI 接手提示词和合同测试；不会包含 `.badmark/`、项目资料、生成图片、日志、依赖缓存或账号凭据。

另一台电脑解压后运行 `node master-kit/scripts/bootstrap.mjs` 即可安装 Bomi智绘。需要创建独立名称、插件 ID 和端口的新工作台时，使用 `master-kit/project.config.example.json` 和 `master-kit/scripts/create-workbench.mjs`。完整说明见 `master-kit/README.md`。

## 数据与恢复

- `.badmark/state.json`：持久项目数据库，原子写入。
- `.badmark/state.json.bak`：上次成功保存的数据库备份。
- `.badmark/state.v1.backup.json`：升级共享资料库前保留的一次性 v1 原始备份。
- `.badmark/files/`：上传原件、标准化图、任务结果。
- `.badmark/deliveries/`：通过插件导出的 ZIP 包。
- `.badmark/server.log`：本机服务日志。
- `outputs/`、`public/`、`项目资料/`：历史归档原文件，保持原路径可用。

备份应同时包含 `.badmark/` 和历史归档目录。恢复数据库前停止本机服务，
核对 `.bak` 后再复制恢复；程序遇到损坏数据库会报错，不会静默清空。
项目删除保留原文件及任务记录，未提供自动清理功能。
运行时数据和凭证不进入 Git。代码改动按 `AGENTS.md` 要求测试并提交。

## 验证

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

回归测试使用独立临时数据库和明确标注的测试图，不触碰实际项目。
覆盖报告渲染、自动执行、部分失败续做、取消防迟到回写、连接恢复、输入与结果路径校验、原件保存、跨项目隔离、
历史版本、ZIP 内容、HTTP 身份/来源边界、真实 stdio MCP，以及桌面/手机纯 UI 工作流。
浏览器测试通过依赖注入使用明确的离线测试提供方，不会调用 AI 或影响实际项目。

一次内置图像工具的真实白底烟雾验收另存于 `outputs/validation/`，与回归测试图分开。
生成和人工检查后，可用 `node scripts/accept-image.js /absolute/generated-image.png` 验证实际回传和导出。
`node scripts/accept-executor.js --live` 会在独立数据库创建一个真实白底任务，自动执行直到通过 HTTP 导出 ZIP；使用账号额度，没有人工提交结果步骤。
这不代表对所有造型或所有模型输出质量作保证。
